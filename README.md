# SI-MITRA KONSERVASI SULTENG — Frontend

Frontend statis (HTML/CSS/JS murni) untuk GitHub Pages. Backend: Google Apps Script (REST API).

Satu-satunya berkas yang perlu diedit: `js/config.js` → isi `API_URL` dengan URL Web App (`/exec`).
Jangan menaruh kata sandi, token, atau kunci rahasia di folder ini: semua berkas bersifat publik.
